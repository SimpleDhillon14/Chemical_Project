Autocatalytic Reaction: A + R → R + R

-rA = -dCA/dt = k·CA·CR

Total concentration C₀ = CA + CR = CA0 + CR0 is constant. Let M = CR0/CA0 (R can never be zero, so M > 0). The linearized test is:

ln[(M + XA) / (M(1 - XA))] = CA0(M+1)·k·t

X-axis = t, Y-axis = ln[(M+XA)/(M(1-XA))]. Slope = CA0(M+1)k.
